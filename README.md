# The use of Large Language Models (LLM) in Maturaarbeit
This repository is dedicated to publishing documents used during the Matuararbeit, which are not shared with the relevant link.
## Usage guide
First prompt is shared under [maturaarbeit-german-academic-editor.md](./maturaarbeit-german-academic-editor.md) and was created with ChatGPT. The <q>hidden</q> files consist exclusively of passages which are too long to fit into one prompt, with the exception of one graphic, for which only grammatical correction was asked. As this repository is open to public, such files are not published here for data protection reasons.
